# Train Ticket

Multi-segment railway booking system. The repository contains a Go backend and
a Next.js frontend as separate applications.

## Repository layout

- `backend/` — Go API, background worker, migrations, and backend documentation.
- `frontend/` — Next.js web application.

See [backend/README.md](backend/README.md) for backend configuration and run
instructions. Frontend setup instructions are in `frontend/README.md`.
